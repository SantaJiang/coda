# 长任务、终端与托盘验收（1.5.0）

源码提交版本为 1.5.1；下述安装包与交互验收使用 1.5.0 构建，版本号调整后另行通过前端测试和类型检查。

验收日期：2026-10-17。使用独立的临时 `CODA_HOME`，未修改真实项目或用户模型配置。未提交、未发布。

## 最终交互与生命周期

- 关闭窗口隐藏到系统托盘；保留原 WebView、后端和运行中的命令。
- 托盘打开原窗口，单实例处理避免再启动后端；真正退出统一清理命令、子进程与内置后端。
- 后端内持有 PTY，无独立任务运行器。后端异常时命令中断；恢复时检查已有结果与项目状态，不自动重放原命令。
- 设置直接提供自动/手动恢复、停止全部/仅停止 AI。旧 `keepBackendAlive` 不再参与决策，并在迁移时移除。
- 终端只保留上方命令切换与下方输出，没有路径、耗时、退出码、停止、搜索或复制按钮。
- 鼠标拖选或终端内全选后，用 Cmd/Ctrl+C 复制；不接受键盘输入或粘贴命令。全选与复制仅作用于当前终端已加载的输出。

## macOS 实际操作

使用真实发布构建的 `.app` 与本机 PTY，模型工具调用由本地测试服务提供确定性响应：

- 全新项目通过真实 npm registry 下载 TypeScript 5.9.3，测试代理限速以稳定覆盖两分钟以上；真实 `bun install` 持续约 183 秒后成功。
- 等待期间多次返回增量结果；AI 随后实际运行编译器并得到 `Version 5.9.3`。
- 点击会话终端入口、切换安装/验证两个终端并查看输出；深浅色界面实际检查。
- 实测终端输入测试文字未进入输出；Cmd+A/Cmd+C 能复制输出，鼠标拖选 `Version` 后只复制所选片段。
- 关闭窗口后命令继续，原桌面/后端 PID 保持；重新启动激活同一实例并恢复窗口。
- 后端被杀后旧命令中断；自动恢复先检查项目，手动恢复等待“继续任务”；只停止 AI 时命令继续且不自动唤醒 AI。
- 实测应用菜单“退出 Coda”及 Cmd+Q：桌面、后端、长命令全部结束，记录保存为 cancelled。
- 强制杀死桌面进程后，后端和命令进程随存活监测退出，任务记录为 interrupted。

审查与复验中已修复：快命令监听注册竞态、日志 `data` 被误当 API 信封解包、空日志触发 WASM 错误、取消遗漏忽略 TERM 的子进程、未打开会话的恢复、历史入口无法重新显示、只读容器的编辑光标，以及 AppKit 默认 Quit 绕过清理流程。Cmd+Q 同时有 WebView 捕获兜底，仍调用同一个原生退出流程。

## 打包与尚待验收

本地 macOS Apple Silicon 构建命令（临时签名，不代表公证发布）：

```sh
cd frontend
APPLE_SIGNING_IDENTITY=- bun x tauri build --bundles app,dmg
```

产物在 `frontend/src-tauri/target/release/bundle/`；应用与内置后端的临时签名通过 `codesign --verify --deep --strict`，DMG 通过 `hdiutil verify`。Windows、Linux 安装包与真实平台进程清理尚未实测，不能声明这些平台验收完成。macOS 托盘菜单的物理点击、通知权限/通知展示及系统关机路径仍需人工验收；已验证关闭隐藏、单实例激活与共用退出处理流程。
